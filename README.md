# JM 本子下载器（图形界面版）

基于开源项目 [JMComic-Crawler-Python](https://github.com/hect0x7/JMComic-Crawler-Python) 封装的本地图形界面，
输入车号即可一键下载整本，并可按需导出 **PDF / ZIP / 长图**，PDF 支持加密。

**程序自带 Python 运行时和全部依赖，不需要另外装 Python，整个文件夹拷到任意 Windows 电脑都能直接用。**

## 运行

双击 **`启动.bat`** 即可。

起不来就双击 **`诊断启动.bat`**，它会把具体报错显示在窗口里（不会一闪而过），
同时程序每次启动都会写一份 `启动日志.txt`，出问题时可以直接看这个文件。

## 目录结构

```
jm_gui/
├── 启动.bat          双击这个启动
├── 诊断启动.bat      启动失败时用它排查，能看到具体报错
├── 安装依赖.bat      libs 损坏或丢失时用来重装依赖
├── app.py            主程序
├── requirements.txt  依赖清单
├── runtime/          自带的 Python 3.10 运行时（约 62MB）
├── libs/             依赖库：jmcomic / img2pdf / pillow / pikepdf 等（约 53MB）
├── downloads/        下载内容（首次下载时自动创建）
├── config.json       界面设置（自动生成，可删）
└── 启动日志.txt      启动信息与错误日志（自动生成，可删）
```

## 迁移

**直接把整个 `jm_gui` 文件夹拷走就行**，换盘符、换电脑、路径带中文都不影响，不需要重新安装任何东西。

- 依赖和运行时都是相对路径引用的，所以能随便搬（这也是为什么没用 venv——虚拟环境绑死绝对路径，一搬就废）。
- 限制：`runtime` 和 `libs` 是 64 位 Windows + Python 3.10 的版本，不能用于 32 位系统。
- 想放到 U 盘随身带也可以，下载目录建议改成 U 盘里的路径，避免写满。

## 用法

1. 在输入框填写车号，支持三种写法，多个车号用空格或逗号分隔：
   - `123456`
   - `JM123456`
   - `https://18comic.vip/album/123456/xxx/`
2. 点「查询」可以先看标题、作者、页数、封面（可选）。
3. 勾选要导出的格式，点「开始下载」（或直接回车）。
4. 下载过程中可以随时点「取消」；日志区会实时显示进度与报错。

### PDF 加密

「PDF 密码」这一行勾选「加密」后，导出的 PDF 需要密码才能打开：

- 密码框**留空 = 自动用车号**（也就是 JM 后面那串数字，比如 JM350234 的密码就是 `350234`）。
- 想自定义就填进去，支持任意字符。
- 没勾选 PDF 格式时，这一行会自动置灰不可编辑。
- 加密依赖 `pikepdf`，已随 `libs` 一起打包，不需要额外安装。

## 输出结构

```
downloads/
└── [JM123456]本子标题/
    ├── [JM123456]本子标题.pdf      勾选 PDF 时生成（整本合并，可加密）
    ├── [JM123456]本子标题.zip      勾选 ZIP 时生成（整本打包）
    ├── [JM123457]章节标题.png      勾选长图时生成（每章一张）
    ├── 1/                          第 1 章的原图
    └── 2/                          第 2 章的原图
```

- **长图**按章节拼接，而不是整本拼成一张：整本几百页拼成单张 PNG 会占用巨量内存，容易失败。
- **保留原图**取消勾选时，导出完成后会删除原图；但只选了一种导出格式时才生效，多选时会自动保留原图（否则后面的格式拿不到图片）。

## 选项说明

| 选项 | 说明 |
| --- | --- |
| 接口 api | 移动端接口，IP 限制少、兼容性好，默认用它 |
| 接口 html | 网页端接口，速度快但限制 IP 地区，被墙或报错时换回 api |
| 代理 | 形如 `127.0.0.1:7890`；留空表示不使用代理（不会继承系统环境变量里的代理） |
| 图片格式 | 默认保持原始格式；转 PNG 体积会变大 |
| 线程 | 同时下载的图片数，网络差就调小到 8~10 |

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 双击 `启动.bat` 没反应 | 双击 `诊断启动.bat` 看报错；或检查 `启动日志.txt` |
| 提示"没找到可用的 Python" | 多半是杀毒软件把 `runtime` 目录删了，恢复该目录即可 |
| 界面提示"依赖缺失" | 运行 `安装依赖.bat` 重装到 `libs` |
| 下载一直重试失败 | 网络问题，切换接口（api / html）、配置代理，或稍后重试 |
| PDF 打不开 | 如果勾了加密，输入密码（默认是本子号） |
